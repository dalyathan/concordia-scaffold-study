## 2. Test sets and scoring

## 3. Decision rule (frozen; the six conditions of the tune rule, applied separately to each set and slice; no pooling of test_same with test_hard)
(a) = mean over the three claude_examples seeds. A set PASSES if all hold: (1) plain - (a) lower bound > 0; (2) (b) - (a) lower bound > 0; (3) always-cheapest - (a) lower bound > 0; (4) plain - (a) on its below cells lower bound > 0 (not applicable if the set has none); (5) no case type present has (a) worse than plain by more than 0.05 (type-mean point estimate); (6) letter mass of (a) >= 0.9 x plain. Paired cell bootstrap over the set's cells, 10,000 resamples, numpy default_rng(0), two-sided 95% percentile; lower bound = 2.5th percentile. Outcome per set: PASSED or NOT PASSED, with the list of failed conditions; slices are exploratory and uncorrected, test_same and test_hard are the two primary results, and a slice with fewer than 8 cells (grid E, 6 cells) is labelled "descriptive only". Conditions 2 and 3 are in effect one test on tune ((b) = always-cheapest); both are kept.
Reported, outside the rule: stated-cost rule minus (a); ceiling minus (a) and (a) minus ceiling by type; teacher-distil and our-method-distil: plain minus each, each minus (a); (b) - a and (c) - a on below and no-cost cells; per-run soft regret of every adapter; slope of the expected offer on the stated cost (below cells; bootstrap over cells); cheapest-option mass by type; overlap strata of the label key with the 100 training cells (current key and the stricter V+C key, counts computed in the script from labels only).

## 4. Allowed wording (fixed now; the script prints the flags)
- Pass on a set: "single-label oracle-equivalent supervision at 100 cells lowers soft regret on that set of the same generator, beyond plain, always-cheapest and the cheapest-label control; Claude's labels equal the script-solved oracle up to a tie rule, so nothing is claimed about teaching."
- The clause "and beyond shuffled labels" is allowed only if (c) minus (a) has lower bound > 0 on BOTH below and no-cost cells of that set (one seed of (c)); otherwise it is dropped.
- A pass may be worded as generalising to cells with new label keys only if plain minus (a) on the cells of that set whose current label key (V, grid name, stated cost or prior) is not among the 100 training cells has lower bound > 0 and at least 8 such cells exist; otherwise a pass is worded as holding on the same generator, largely on repeated parameter combinations (26 of the 60 test_same cells overlap on the current key and 49 of 60 on V and C; hard_V has no overlap).
- test_hard slices: a pass is worded as "transfer to unseen resale values / grids / wordings" only if test_hard as a whole PASSED and that slice PASSED; slices are exploratory and uncorrected, test_same and test_hard are the two primary results and are not corrected against each other. Condition 4 is descriptive and excluded from a set's outcome when the set has fewer than 8 below cells (all three slices and grid D); a set with fewer than 8 cells gets no PASSED/NOT PASSED label at all.
- Fail: report the numbers and say the tune result did not carry to that set (or not on the listed conditions). Condition 5 is a point-estimate cutoff of 0.05, so a narrow failure of it is not strong evidence of harm; the failed condition is named.
- Conditions 2 and 3: on test, (b) is a trained model and may differ from always-cheapest; both must pass as written. The stated-cost rule is an oracle on below cells by construction (its regret there is 0) and is outside the rule; a pass shows better than plain, cheapest and (b), not "approaches the oracle".
- No equality-with-ceiling claim (one ceiling seed); no "examples beat instructions" (teacher-distil and our-method-distil are different target types); those rows are reported, not tested against a rule.
- Reported per (a) seed: plain, (b) and always-cheapest minus each seed; (b) has one seed, so intervals ignore seed variance and the single training draw.
