## 0. What the development evidence says (so you can decide whether the one look is worth spending)

## 1. Question and claims
Q1 (primary): on cells like the training cells (test_same), does the frozen teacher-distil adapter lower soft regret relative to plain and wrong-rule-distil (and neutral-distil if decision D1 option B is chosen), without harm on at-or-above and no-cost cells?
Q2 (primary, second comparison): is teacher-distil different from our-method-distil?
Q3 (descriptive per slice): on test_hard slices (resale values, price grids and wordings never seen in training), does the gain over plain survive? Each slice is its own result; nothing is pooled with test_same.
No claim about mechanism (tracking the stated cost) is made or tested beyond the reported slope and cheapest-option mass.

## 4. Primary comparisons (test_same only; no pooling with test_hard)
Metric: cell-mean soft regret (first-token letter probabilities, five cyclic orders). **One sign convention everywhere: gain = control regret minus teacher-distil regret; positive means the teacher is better.** Paired cell bootstrap, 10,000 resamples, numpy PCG64 seed 0, 95% percentile interval, resampling cells **stratified by type** (20 per type; hard slices by their own types) with the same resample indices for every comparison. No multiplicity correction: SUPPORT is an intersection of conditions, P4 is a separate two-sided question, slice labels are exploratory and uncorrected. Cells share values of V, grid and prior, so the independence assumption is optimistic.
P1 gain vs plain (also the below-cell gain: lower bound > 0 and teacher better in >= 60% of below cells; and by-type gains); P2 gain vs wrong-rule-distil, computed twice: with the teacher's 3-seed average (primary) and with teacher seed 0 only against the one wrong-rule seed (sensitivity on equal footing); P4 gain of our-method-distil minus teacher (two-sided). P3 (vs neutral-distil) exists only under decision D1 option B; under the default there is no neutral-distillation control and none is claimed. Always-cheapest and the stated-cost rule are secondary comparators, reported overall and by type for test_same and each slice. Descriptive and reported always: by-type tables, overlap strata, slope on stated cost with bootstrap interval, mass on the cheapest option by type, letter mass overall and per type, per-seed values, in-prompt text rows, the ceilings, P2 on below cells.

## 5. Outcome labels (written before the look; ordered decision lists, so every possible outcome gets exactly one headline label)
test_same headline, first matching rule wins:
1. **WORSE:** P1 upper bound < 0.
2. **NOT SHOWN:** P1 lower bound <= 0 (read only as "not shown on these 60 cells"; no second look, no re-tuning, no new arm).
3. **SMALL-GAIN:** P1 lower bound > 0 but the point gain < 0.15.
4. **SUPPORT:** point gain >= 0.15 AND below-cell condition holds AND P2 lower bound > 0 in both the primary and the sensitivity version (AND P3 lower bound > 0 if option B) AND no HARM AND letter mass >= 0.9 x plain overall and in each type AND teacher is not worse than always-cheapest (upper bound of always-cheapest-minus-teacher >= 0). A tag follows: "beats always-cheapest" (lower bound > 0), "not separated from always-cheapest" (interval contains 0).
5. **PARTIAL:** otherwise (point gain >= 0.15 and lower bound > 0); the failed conditions are listed.
HARM = gain vs plain < -0.05 (point estimate) on at_or_above or on no_cost test cells; it is a listed failed condition (blocking SUPPORT) and is printed whatever the headline is.
P4 label, first matching rule wins: EQUIVALENT (whole interval within +-0.10); TEACHER-BETTER (lower bound > 0); OURS-BETTER (upper bound < 0); INCONCLUSIVE.
Hard slices (hard_V, hard_grid D, hard_grid pooled, hard_wording; grid E descriptive only), exploratory and uncorrected, each labelled from teacher-minus-plain gain on all its cells: TRANSFERS (lower bound > 0), WORSE (upper bound < 0), NOT SHOWN otherwise (checked in that order); printed beside it: n cells, by-type gains (primary for reading), always-cheapest gain, HARM per type, letter mass. The label function is unit-tested on synthetic intervals (including all boundaries) before the lock. The frozen development verdict "NOT PASSED" is printed next to every test result.

## 6. Pre-registered expectation and power
Development (tune, gain = plain regret minus teacher regret): below +0.76, at_or_above +0.27, no_cost -0.19 (harm). I therefore expect test_same to come out PARTIAL with HARM on no_cost cells and a result near zero against always-cheapest; SUPPORT would be a surprise. Half-width of the P1 interval on 60 cells expected about 0.13-0.15; slice intervals at 7-10 cells per type are wide.

## 9. Decisions for the owner (defaults used if you answer only "approved")
D1. Neutral control: the neutral-distil arm equals plain (best epoch 0 on all three seeds; at epochs 1-2 it is worse than plain on the selection set). Option A (default, no GPU): there is no neutral-distillation control; P3 is dropped and not claimed (wrong-rule distillation is then the only distillation control). Option B (about 1.3 GPU hours on train/tune cells only, before any test look; each new run set needs G1 by Sonnet, under 3 GPU hours): run three neutral seeds for a fixed 3 epochs (the teacher's median best epoch), freeze them and use them as the neutral arm.
D2. Wrong-rule seeds 1-2 (about 1.4 GPU hours, train/tune only): default no; with only one wrong-rule seed P2 is reported with that caveat. Choose yes if you want P2 on equal seed count.
D3. Should the one look be spent at all, given NOT PASSED on tune? Default: yes, as a descriptive pre-registered look. Trade-off: spending it now leaves no clean test set for a later version whose paragraph fixes the no-cost branch; waiting would let a revised paragraph (new loop, new selection and tune split) use these test sets once.
D4. Ceiling rate for the reference row: both rates are scored and reported; neither is a comparator.
