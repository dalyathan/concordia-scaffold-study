# GEN_PLAN.md — LoRA arms on the generated dataset (written before training)

## Question
Can a method paragraph written by Claude from Gemma's own failures (the "teacher method", frozen in demo/gen/teacher_method.txt after a closed loop: the round-1 paragraph, sha256 f41ae9b32010fcf2dbf87a7d207393eed31cf6a99294a7ed425abb98abf9b4b9; the first paragraph is kept as teacher_method_v1.txt, sha256 d4010305b297188598d0fb87186ed8fdb2ef0c98446dec70240a7f74f46c3499) be distilled into rank-4 LoRA weights so that plain-prompt Gemma 2 9B-it makes better offers on unseen generated cells? Evidence comes from the TUNE cells only; test_same and test_hard are not touched, and nothing here is a test result.

## Data (all from demo/gen/, CPU-generated; only train and tune cells are read)
- Training set: 100 of the 300 train cells (34 below-resale, 33 at-or-above, 33 no-cost; demo/gen/lora_train_cells.json), one fixed name variant per cell, three fixed option orders per case = 300 examples per arm. Reduced from the 300 cells for the 8-hour budget (a pass costs about 1 s; the full set would take about 1 hour per epoch).
- **Selection set B** (demo/gen/lora_select_cells_B.json): 42 train cells outside the 100 training cells, outside the teacher-loop set A (lora_select_cells.json, on which the paragraph was chosen) and outside the 50 cells of the original teacher packet (14 per type), name variant 0, five orders. The lr choice and early stopping use this set only.
- **Tune set** (42 cells x 2 name variants, five orders): scored once per run, at the best epoch, and used for the verdict only; it is not used for any selection. Tune numbers are therefore not selected-on (only the run is).
- Reference rows on tune (no training): plain, the teacher text in the prompt, the original method text in the prompt, neutral text, wrong rule (step B), always-cheapest and the stated-cost rule (computed from labels).

## Arms (five; targets over the five option letters)
1. **teacher-distil:** the model's own first-token letter distribution with the teacher paragraph as the Notes block, computed before training.
2. **our-method-distil:** same with the earlier method paragraph (textrows.METHOD). 3. **neutral-distil:** same with 150 tokens of market-scene text. 4. **wrong-rule-distil:** same with "Offer half the stated cost."
5. **answer-trained ceiling:** uniform over the letters of the case's best offers (supervised, not a method).
Training uses the full-vocabulary letter loss (cross-entropy of the answer letter against the target using the letters' full-vocabulary log-probs, so letter mass is protected), rank 4, alpha 8, q/k/v/o, fp32 adapter weights, AdamW, one optimizer step per case, gradient checkpointing, at most 5 epochs, early stopping on the selection set (patience 2). Same code path for all arms (demo/gen_lora.py).

## Seeds and learning rate
lr grid {1e-4, 3e-4, 1e-3} at seed 0 chosen on the SELECTION set by lowest soft regret (ties to the lower lr); 3 seeds per arm at the chosen lr, subject to the budget ladder below. Every arm is compared at its own chosen lr when it has a grid, else at the teacher's chosen lr.

## Budget: 8 GPU-hours (measured, not assumed)
The estimate is runs x measured seconds per run (mean wall_s of finished runs; 2400 s assumed until one finishes, because the first G1 review found the earlier 0.6 h assumption several times too low). The chain re-plans after the first runs and has a cumulative wall-time guard. Ladder, first plan that fits (demo/gen_chain.py --plan): L0 full 23 runs; L1 controls and ceiling at the teacher's lr only 17; L2 also our-method at the teacher's lr only 15; L3 neutral and wrong-rule 2 seeds 13; **L4 our-method 2 seeds 12 runs (8.0 h at 2400 s; chosen provisionally)**. The controls' lr grid was dropped first, as instructed. Consequence declared now: the teacher arm gets a 3-point lr grid and the controls do not, which favours the teacher; the pass rule below is therefore also required of seeds 1-2 and reported against the controls at the teacher's lr only.
Order of work: precondition check; teacher lr grid; answer-trained ceiling; neutral seed 0; wrong-rule seed 0; our-method seed 0; teacher seeds 1-2; our-method seeds; control seeds.
**Preconditions and stop rules (G1):** (a) before any run, the in-prompt teacher text must beat both plain and the neutral text on the selection set (demo_out/gen_text_rows.jsonl); otherwise no LoRA run starts. (b) Halt if all three teacher runs keep epoch 0. (c) Halt if the answer-trained ceiling does not improve on plain. (d) Halt if teacher-distil is not better than neutral-distil on the selection set at seed 0. (e) A run whose best epoch is 0 is a "no improvement" result, flagged and not counted as an arm. (f) The log of the targets' own regret (the in-prompt teacher text on the 100 training cells) is reported.

## Pass rule (on TUNE cells, frozen now)
Per-cell tune soft regret (mean of the two name variants, then mean over an arm's seeds). Teacher-distil PASSES only if ALL hold:
1. its mean over cells is below plain, neutral-distil and wrong-rule-distil and, for each of the three, the lower 95% bound of the paired cell bootstrap of (control - teacher) (10,000 resamples, seed 0, 42 cells) is above 0;
2. effect floor: the mean improvement over plain is at least 0.15 soft regret;
3. cost-below cells (14): the teacher improves on plain with the lower bound above 0, and improves in at least 60% of those cells;
4. no harm: on at-or-above and no-cost cells the teacher's mean soft regret is no worse than plain + 0.05;
5. letter mass at least 0.9 x plain overall and per type.
The same must hold for seeds 1-2 only (seed 0 chose the lr) against all available control seeds. Reported alongside, not part of the rule: teacher vs our-method-distil; all arms against always-cheapest (a shift toward cheap offers alone beats plain: the teacher must improve on the below cells, rule 3) and the stated-cost rule; the answer-trained ceiling; by case type; by whether a tune cell's label key (V, grid, C or prior) occurs among the 100 training cells (30 of 42 tune cells overlap with the 300 train cells; overlap with the used 100 is computed); the slope of expected offer on stated cost (below cells); train-sample regret; per-seed values; the in-prompt teacher text as the upper reference. Limits declared: seeds vary only the LoRA initialisation and example order (not the training cells), so seed spread understates training-set variance; the bootstrap is over cells only; the wrong-rule text says nothing for the two thirds of cells without a stated cost, so wrong-rule is a weak control there (also report the comparison on below cells). A pass on tune is not a test result; the test look is a separate plan (GEN_TEST_PLAN.md).

## Safety
Before training the training forward path (loss_on) is asserted to equal the scoring path (letter_scores) on three cases at the zero-initialised adapter (log-prob difference below 0.01 nats); epoch 0 scoring is asserted to equal the saved plain scores on the selection set (1e-3); after training the best adapter is reloaded with no unexpected keys and the selection score is asserted to equal the one recorded at the best epoch (1e-3). Adapter-off equality and cross-process reload were verified earlier by demo/lora_checks.py on the same PEFT path. Adapters are gitignored; hashes are in the run JSONs, committed after every run. Old adapters are not used; test cells are not read. Gates: G1 (Sonnet + Opus, over 3 GPU-hours) done: both go-with-changes, changes applied; G2 (Sonnet + Opus) before any verdict.
